01 // VISIÓN_GENERAL

Este proyecto consistió en el diseño y despliegue de una infraestructura de nube privada simulada para un entorno corporativo de alta seguridad. El objetivo principal fue crear un ecosistema donde el tráfico de datos fuera rastreable y estuviera segmentado por funciones críticas, minimizando la superficie de ataque.

FIG 01: Topología Lógica de Segmentación de Red y Control de Tráfico.

02 // IMPLEMENTACIÓN_TÉCNICA

  • Virtualización de Capas: Utilización de Proxmox VE para orquestar contenedores LXC dedicados a microservicios y VMs para bases de datos relacionales.
  • Gateway de Seguridad: Implementación de un clúster de pfSense con balanceo de carga (HAProxy) para gestionar las peticiones entrantes y mitigar ataques de denegación de servicio (DoS).
  • Monitorización Persistente: Despliegue de una pila ELK (Elasticsearch, Logstash, Kibana) para la visualización de logs de seguridad y detección de intrusiones en tiempo real.

03 // CONCLUSIONES_DEL_NODO

El despliegue final demostró una mejora del 40% en la eficiencia de respuesta ante incidentes gracias a la centralización de logs. La arquitectura Zero-Trust implementada garantiza que incluso en caso de brecha en la DMZ, los datos internos permanezcan cifrados y aislados.
