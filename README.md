ALEX.LABS // Control Center v1.0
Repositorio de Infraestructura y Gestión de Sistemas
Este proyecto consiste en un Dashboard de Control de Infraestructura diseñado con una interfaz de terminal de comandos. Funciona como un nodo centralizado para la documentación de proyectos de ciberseguridad, administración de redes y automatización de sistemas.

Tecnologías Utilizadas
HTML5: Estructuración semántica de los documentos y nodos de información.

CSS3: * Diseño Responsivo mediante Media Queries para adaptabilidad en dispositivos móviles.

Arquitectura basada en Variables CSS para la gestión de la paleta de colores técnica.

Layouts complejos utilizando CSS Grid y Flexbox.

JavaScript (ES6+): Implementación de lógica funcional sin librerías de terceros.

Implementación de JavaScript
El proyecto integra tres funcionalidades principales basadas en JS:

Algoritmo de Filtrado Dinámico: Ejecuta una búsqueda en tiempo real sobre el DOM para filtrar proyectos por cadena de texto o categoría técnica, gestionando la visibilidad de los nodos de forma eficiente.

Sincronización de Reloj UTC: Módulo que captura el tiempo del sistema, lo formatea bajo estándares ISO y lo actualiza cada 1000ms mediante un intervalo de ejecución.

Controlador de Despliegues (Accordion): Lógica encargada de gestionar el estado de los contenedores de información, permitiendo la expansión y contracción de datos técnicos de forma jerárquica.
